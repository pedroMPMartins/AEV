With all of that said, it appears as if the site is vulnerable to XSS. When going to this link:
`http://10.110.3.72:8021/?q=<script>alert(1)</script>`

It will display **1** in an alert box. So we can try to call the `grant()` function to get the flag.

Unfortunatly, it seems it won't be so easy, as we get this error in the console:
`Uncaught ReferenceError: grant is not defined`

However, we can inject a cookie that will then redirect us to the flag, when we have the cookie. We can do it with this link:
`http://10.110.3.72:8021/?q=<script>document.cookie='xss_grant=1;path=/';location.href='/flag';</script>`
